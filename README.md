# 🌍 Country Info Finder

Country Info Finder is a simple and responsive web application that lets users search for any country and view important details instantly.

## ✨ Features
- Search any country by name
- Displays country flag
- Shows:
  - Common & official name
  - Capital city
  - Currency
  - Population
  - Languages
- Displays country location using Google Maps
- Clean UI using Bootstrap 5

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Fetch API)
- Bootstrap 5
- REST Countries API
